# Футболна Академия Герман — Static Website

Готов статичен frontend прототип според UI/UX спецификацията.

## Файлове
- index.html — цялата One-Page структура
- styles.css — responsive дизайн
- script.js — меню, scroll reveal, news modal, demo form
- assets/hero.jpg — добавете реалната hero снимка
- assets/training.jpg
- assets/IMG_3277.jpg
- assets/IMG_3280.jpg
- assets/IMG_3276.jpg

## Важно преди production
1. Заменете демонстрационните изображения с реални снимки.
2. Потвърдете реалните възрастови групи.
3. Потвърдете всички твърдения за Аспарух Василев, Borussia Dortmund и Schalke 04.
4. Добавете реален телефон, email и социални URL адреси.
5. Свържете регистрационната форма със server-side endpoint/form provider.
6. Добавете реалните sponsor URLs.
7. Добавете Privacy/Cookie страниците.
8. Настройте Google Analytics/Tag Manager и Search Console според GDPR изискванията.
9. Добавете реална карта чрез lazy-loaded embed/API.
10. Направете SEO migration и 301 redirects от старите URL адреси.

## Стартиране локално
Отворете index.html или използвайте:
python -m http.server 8000

След това:
http://localhost:8000
