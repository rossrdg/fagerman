# Футболна Академия Герман — сайт, админ панел и родителски портал

Уебсайт на Футболна Академия Герман (Герман, район Панчарево, София) с админ панел за треньорите и портал за
родителите. Backend: **Flask + SQLite**; frontend: чист HTML/CSS/JavaScript (без build стъпка).

## Какво включва

**Публичен сайт**
- Начална страница: за академията, отбори, методика, главен треньор, новини, галерия, партньори, форма за пробна
  тренировка, контакти.
- `/teams/<адрес>` — страница на отбор (график, мачове, галерия, клипове, връзка към класирането);
  `/schedule` — тренировъчен график; `/matches` — седмичен афиш с мачове и резултати;
  `/news` — новини; `/gallery` — албуми; `/coaches` — треньорите; `/shop` — магазин; `/privacy` — политика за лични данни.

**Админ панел** (`/admin-login.html`) — записани за пробна тренировка, новини, отбори и смяна на сезона, график,
мачове (с импорт от Excel), треньори и вратарски групи, потребители, магазин, поръчки и отчети, а също:
- **Футболисти** — профили на децата, родителски акаунти (временна парола по имейл), документи за картотекиране;
- **Такси** — месечни и еднократни такси, отбелязване на плащания, отчет и CSV;
- **Известия** — известия към родителите (за всички, за отбор или за дете), по желание и по имейл.

**Родителски портал** (`/parent-login.html`) — вход с имейл и временна парола (смяна и съгласие с политиката при
първия вход); картотекиране на децата: качване на документи, проверка от треньора, **попълване на бланките на БФС
онлайн** (данните не се запазват); напомняния за неплатени такси и известия от академията. Няма онлайн плащане.

### Кой какво вижда

| Роля | Права |
|------|-------|
| Главен админ (`owner`) | всичко, вкл. потребители, смяна на сезона и истинско изтриване |
| Главен треньор (`head_coach`) | футболисти, документи, такси, известия, магазин, треньори; не управлява потребители |
| Треньор (`coach`) | записани за пробна, новини, отбори, график, мачове, галерия; само **своите** играчи, само за четене, без родителски данни, документи и такси |
| Родител | само своя акаунт и децата си; няма достъп до админ частта |

## Структура

```
backend/            Flask приложение (app/), конфигурация (config.py), тестове (tests/), CLI (flask --app run ...)
  app/routes/       маршрути: публични страници и API (/api/...)
  app/templates/    Jinja шаблони за публичните страници
  bfs_templates/    официални бланки на БФС + fields.json (позиции на полетата)
  fonts/            шрифт Carlito за попълване на бланките
frontend/           статичните страници (index.html, admin-*.html, parent-*.html), CSS и JS
backend/README.md   подробности: API, роли, документи, бланки, такси, известия, защити
```

## Бърз старт (локално)

```powershell
cd backend
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env                      # попълнете по нужда (виж по-долу)
flask --app run create-owner <потребител> --name "Име"   # главен администратор (пита за парола)
flask --app run seed-teams                  # отборите U6–U15 и MEN
flask --app run seed-schedule               # тренировъчният график (след seed-teams)
python run.py                               # http://127.0.0.1:5000
```

Базата `backend/fagerman.db` се създава сама при първо стартиране. Без `MAIL_SERVER` имейлите **не се изпращат**, а само
се записват в лога на сървъра (тестов режим) — така се виждат временните пароли и текстовете. За автоматично презареждане
при разработка добавете `FLASK_DEBUG=1` в `.env` (никога на сървъра).

## Настройки (`backend/.env`, образец: `.env.example`)

| Променлива | За какво |
|------------|----------|
| `SECRET_KEY` | дълъг случаен низ; **задължителен** в production (без него приложението не стартира) |
| `SESSION_COOKIE_SECURE` | `1` при HTTPS (production) |
| `SITE_URL` | публичният адрес (напр. `https://fa-german.eu`) — за абсолютни връзки и имейлите |
| `MAIL_SERVER`, `MAIL_PORT`, `MAIL_USE_SSL`, `MAIL_USE_TLS`, `MAIL_USERNAME`, `MAIL_PASSWORD`, `MAIL_FROM`, `MAIL_FROM_NAME`, `MAIL_REPLY_TO` | изходящ имейл (SMTP) |
| `DOCS_KEY` | ключ за шифроване на документите за картотекиране; **задължителен** в production (генерира се с `Fernet.generate_key()`, виж `.env.example`) |
| `DOCS_DIR`, `UPLOAD_DIR` | папки за шифрованите документи и за качените снимки (извън git) |
| `SHOP_ORDER_EMAIL`, `SHOP_ORDER_LIMIT`, `SHOP_ORDER_WINDOW_SECONDS` | магазин: имейл за нови поръчки и защита от спам |
| `DATABASE_URL`, `CORS_ORIGINS`, `FRONTEND_DIR`, `SESSION_HOURS` | база, CORS, папка на frontend, живот на сесията |
| `FLASK_DEBUG` | само локално |

## Команди

`flask --app run <команда>`: `create-owner`, `reset-password`, `list-users`, `seed-teams`, `seed-schedule`,
`set-season`, `import-matches` (програма от Excel), `import-products` (артикули за магазина).

## Лични данни и сигурност

- Документите (лични карти, актове за раждане, медицински) са **шифровани** на диска, извън публичните папки, и се
  четат само през проверени адреси: родителят — своите, главният треньор и главният админ — всички.
- Данните от формата за бланките (ЕГН, лична карта, имена) **не се запазват никъде** — нито в базата, нито в
  логовете или сесията (проверява се автоматично от тестовете).
- Отделни входове и сесии за админите и родителите, CSRF защита, заключване след 5 грешни паролата, временната
  парола изтича след 7 дни. „Изтриване“ на футболист само архивира; истинско изтриване — само главният админ.
- Таксите се виждат само от главния треньор, главния админ и самия родител.

## Пускане в production — списък

1. **Хостинг:** Python версия и `pip install -r requirements.txt` (особено `cryptography`, `Pillow`) — проверете рано.
2. **`.env`:** `SECRET_KEY`, `SESSION_COOKIE_SECURE=1`, `SITE_URL`, `DOCS_KEY`, `MAIL_*`, `SHOP_ORDER_EMAIL`.
3. **WSGI**, не `python run.py` (файл за cPanel още не е добавен). Само през HTTPS.
4. **Първо стартиране:** `create-owner`, `seed-teams`, `seed-schedule`.
5. **Бекъпи:** базата, `UPLOAD_DIR`, `DOCS_DIR` **и `DOCS_KEY`** (без ключа документите не се четат).
6. **Опитайте** с тестови родител и дете: имейл с парола, вход, смяна на парола, качване, проверка, бланки, такси.
